# Compound English words typed as one token ("dashboard" = dash + board).
# The dictionary only holds simple words, so past the first piece the keystrokes
# stop looking English and the Telex transform keys inside start eating letters
# ("dashboard" -> "dáhboard", "airdrop" -> "aidrop"). isEnglishCompound() teaches
# both the keystroke-time check and the word-break restore to see the split.
#
# Every line carries a trailing token so the word actually ends: the fixture
# reader strips trailing whitespace, and these cases are about the FINAL text
# after a word break. Mid-word a diacritic may still flash before the restore.
@input=telex
@detect=on

# --- Telex accepts the tone key anywhere after the vowel, so "chiếm" can be
#     typed "chiseem" as well as the canonical "chieems". Only the canonical
#     spelling is in the dictionary, so a tone-first one is invisible to
#     isVietByTelexPrefix() and splits cleanly into English pieces
#     ("chi"+"seem") — it must still come out Vietnamese. Found by review; the
#     narrow rawToneReorderIsViet() does not cover these because it also
#     requires the canonical form to be an English word, which "chieems" is not.
#     renderedIsViet() looks up the word the engine actually produced instead, so
#     every key order that lands on a Vietnamese word is covered.
chiseem ok => chiếm ok

chofan ok => choàn ok

choram ok => choảm ok

# "sieuse" used to come out "siêu" while "dieuse" one line up came out "diếu" —
# the same shape, differing only in the initial consonant, because that consonant
# is the tone letter and got counted as a second press of the tone key. It now
# keeps its mark like its neighbour.
